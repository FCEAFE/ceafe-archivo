# ceafe-archivo

Permanent public archive of CEAFE [Notas de Actualidad](https://www.ceafe.eu/) section PDFs and edition podcasts, in Spanish and English.

This repository is **append-only**. New days are added; old files are never deleted and history is never force-pushed.

- Site: https://fceafe.github.io/ceafe-archivo/
- Layout: `pdf/YYYY/MM/YYYY-MM-DD/HHMM/<section>.pdf` (English) and `<section>_es.pdf` (Spanish), one folder per edition (from 19 Nov 2026: weekdays 08:30, 14:30, 20:30; weekends 14:30, 20:30). The 07:30 edition of 19 Nov 2026 is kept. Earlier days: 07:30, 13:30, 20:30 and weekend 14:00, 20:30. Days before 16 Nov 2026 have a single daily edition at `pdf/YYYY/MM/YYYY-MM-DD/<section>.pdf`.
- Podcast: `audio.mp3` (English) and `audio_es.mp3` (Spanish) in the same edition folder, 64 kb/s mono, when that edition has a recording.
- Catalogue: `archive.json` and the bilingual `index.html`.
