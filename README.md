# ceafe-archivo

Permanent public archive of CEAFE [Notas de Actualidad](https://www.ceafe.eu/) section PDFs, in Spanish and English.

This repository is **append-only**. New days are added; old files are never deleted and history is never force-pushed.

- Site: https://fceafe.github.io/ceafe-archivo/
- Layout: `pdf/YYYY/MM/YYYY-MM-DD/HHMM/<section>.pdf` (English) and `<section>_es.pdf` (Spanish), one folder per edition (weekdays 07:30, 13:30, 20:30; weekends 14:00). Days before 16 Nov 2026 have a single daily edition at `pdf/YYYY/MM/YYYY-MM-DD/<section>.pdf`.
- Catalogue: `archive.json` and the bilingual `index.html`.
